# Runtime exports

Store approved, game-ready exports here, grouped to mirror `art/source/`.

A `webp/` folder next to background exports holds the lossy WebP copies the single-file build embeds
(`tools/art_bg_webp.py`, with an `index.json` of the PNG each was made from). The PNG beside it is the master.

Exports must preserve the approved artwork. Record any resizing, palette conversion, compression or other technical processing in the corresponding manifest. Never replace missing source layers with invented or regenerated art.
