# Art manifests

Each asset pack should have a manifest documenting:
- asset pack name and status (PROPOSED / IN REVIEW / APPROVED / IMPLEMENTED / SUPERSEDED);
- source and export file paths;
- canvas dimensions, color mode, alpha/transparency and format;
- layer names and render order;
- tileability and intended parallax behavior, where relevant;
- technical processing applied to exports;
- visual approval and implementation status.

A manifest records what exists; it must not imply that a planned or missing file has been delivered.
