# Prebujenje — folk-art illustration

**Status:** Subject CONFIRMED; artwork deferred.

Depict Kralj Matjaž awakening and restoring his company. His soldiers begin to rise with him; the composition suggests renewed strength and protection.

The rank-3 attack against all enemies is a gameplay effect and should not force an invented folkloric event into the image. A winter linden coming into leaf may be included as a motif from some versions of the tradition, but is not mandatory.

Use the project's traditional folk-art direction, with panjske končnice as an important reference.
