# Ajdovska deklica — gameplay sprites

This folder holds the in-game pixel-art assets for Ajdovska deklica.

## Required assets
- Party / overworld idle sprite.
- Battle idle sprite.
- Metanje skal animation.
- Varstvo popotnikov activation / protection animation.
- Okamnitev activation animation (if the character has a dedicated caster animation).
- Any approved hit, victory, defeat, or status animations required by the shared character animation standard.

## Art direction
- Modernised SNES/GBA-inspired pixel art.
- Match the project's established pixel density, palette, outline weight, proportions, and sprite dimensions.
- Keep the silhouette readable at mobile gameplay scale.
- Do not use folk-art illustration style for gameplay sprites.

## Naming
Use descriptive lowercase filenames, for example:
- `ajdovska-deklica-idle.png`
- `ajdovska-deklica-metanje-skal.png`
- `ajdovska-deklica-varstvo-popotnikov.png`
- `ajdovska-deklica-okamnitev.png`

No final assets are present in this folder yet.
