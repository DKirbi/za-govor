# Ajdovska deklica — folklore references

Store source scans, bibliographic notes, verified excerpts, and visual reference links here. Do not add copyrighted book scans unless the project has permission to store them.

## Initial source list
- Triglav National Park, *Miti in legende pod Triglavom*.
- Dušica Kunaver, *Slovenska dežela v pripovedki in podobi* (1991).
- ZRC SAZU, Language Advisory Service, entry/advice concerning *ajdovska deklica*.

## Research record
For each source, record:
- Full bibliographic details (author / institution, title, publisher, year).
- Page number or URL.
- Which folklore claim it supports.
- Whether it is a primary record, scholarly analysis, institutional retelling, or later popular retelling.
- Any differences between versions of the story.

Do not treat the source list as a substitute for checking exact passages and page references.
